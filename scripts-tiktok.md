# Scripts TikTok — Lancement PostIA (cible : débutants)

Format : enregistrement d'écran de PostIA + voix off (ou texte à l'écran).
Durée cible : 15-25 secondes. Toujours filmer en vertical (9:16).

### Comment enregistrer l'écran proprement (sans que l'outil apparaisse)

1. Appuie sur **Cmd + Maj + 5** (outil intégré du Mac)
2. Dans la barre qui s'affiche, choisis **"Enregistrer la partie sélectionnée"**
3. Ajuste le cadre pour ne couvrir QUE la fenêtre PostIA (sans le Dock ni la barre de menus)
4. Clique "Enregistrer" : la barre d'outils disparaît automatiquement dès que l'enregistrement démarre — elle n'apparaît jamais dans la vidéo
5. Pour arrêter : clique le bouton ⏹ dans la barre de menus en haut à droite (hors du cadre enregistré, donc invisible dans la vidéo)
6. Monte ensuite la vidéo dans CapCut : recadre en vertical 9:16, accélère les passages d'attente, ajoute les textes

> "Tu n'y connais RIEN en réseaux sociaux ? Regarde ça."

1. Tu choisis une catégorie (ex: Food) et un thème ("Recette rapide")
2. Tu cliques "Générer mon post"
3. La progression s'affiche, puis le carrousel apparaît : 3 images + le texte prêt
4. Zoom sur le résultat final

## Règles de publication

- Rythme : 1 vidéo tous les 2 jours minimum (l'algo récompense la régularité)
- Poste entre 12h-14h ou 19h-21h (heures françaises)
- Réponds à TOUS les commentaires les premières 24h (signal fort pour l'algo)
- Mets le lien postia.cloud en bio dès maintenant
- Une vidéo qui ne décolle pas ≠ échec : il faut souvent 10-15 vidéos avant la première qui "prend"
- Republie les mêmes vidéos sur Instagram Reels et YouTube Shorts (copier-coller gratuit de visibilité)
